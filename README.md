# Kakeibo — offline expense tracker (PWA)

A household-budget app inspired by apps like Zaim, built as a static Progressive Web App.
No server and no account: data lives in the browser's local storage on each device. It works offline and installs to the home screen.

## Features
- **Entries:** expense / income / transfer, with categories, sub-genres, account, place (with autocomplete) and memo
- **Receipt scanning** (📷 in the new-entry sheet): runs entirely on the device with Tesseract.js, in English or 日本語. It finds the total, date, store and currency, then guesses the category from the store name or from your past entries at the same place. The OCR engine downloads on first use and is cached for offline use. Photos are not stored or uploaded. The code is in `receipt.js`.
- **Calculator-style amounts:** type `120+35` or `3*45`
- **Home:** monthly income / expense / balance summary, budget progress and search
- **Calendar:** daily totals per day; tap a day to see or add its entries
- **Report:** category donut chart, per-category budgets and a 6-month income-vs-expense trend
- **Accounts:** live balances and net worth (cash, bank, cards, e-wallets)
- **Budgets:** monthly total plus per-category limits
- **Customizable categories:** icon, color, genres and order
- **Backup:** export/restore JSON, export CSV for spreadsheets
- **Multi-currency:** each account and entry has its own currency (PHP, JPY and USD by default). Totals convert into the display currency you pick (tap ₱/¥/$ in the top bar). Each entry locks the exchange rate for its own date: today's live rate (open.er-api.com) for new entries, or the historical ECB rate (frankfurter.dev) for past dates. You can override it per entry. Account balances and net worth use current rates.
- **Sync between devices** (More → Sync devices): data is encrypted on the device (AES-GCM, with a key derived from your passphrase) and stored in a secret gist in your own GitHub account. It's offline-first: changes queue while you're offline and sync when you reconnect or reopen the app. Changes merge entry by entry, and the newest edit wins. The token and passphrase stay in that device's storage only. The code is in `sync.js`.
- **Recurring entries** (rent, subscriptions, salary, savings transfers): set **Repeat** on any entry, or manage them under More → Recurring. Options are weekly, every 2 weeks, monthly (including the 31st or the last day), every 3 or 6 months, and yearly, with pause and end dates. Due entries are added when the app opens. Generated IDs are `<rule>~<date>`, so synced devices never double-post and deleted occurrences stay deleted. Home shows what's coming up this week. The code is in `recurring.js`.
- **Monthly summary:** a summary screen for any month (Report → 📋), a "summary ready" card on Home for the first week of each month, and an optional notification (More → Settings). The notification text is built on the device and cached in IndexedDB. The service worker shows it from Chrome's periodic background sync (installed Android app) or when the app is next opened, whichever comes first. The code is in `notify.js` and `sw.js`.
- **Settings:** light/dark/auto theme, week start

## Run locally
```bash
python -m http.server 8765
```
Open http://localhost:8765. Service workers don't run from `file://`.

## Deploy (GitHub Pages)
Push to a GitHub repo, then go to **Settings → Pages → Deploy from a branch → `main` / root**.
The site appears at `https://<user>.github.io/<repo>/`.

**When you change files, bump `VERSION` in `sw.js`.** Otherwise installed copies keep the old cached files.
The new version loads on the next app launch after the update downloads.

## Notes
- Data is per device and per browser. Use **More → Backup & data** to move data or keep it safe.
- Icons are generated by `tools/make-icons.ps1`.
